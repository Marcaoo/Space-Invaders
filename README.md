# Space-Invaders
Space Invaders em Java  Projeto de um jogo inspirado no clássico Space Invaders, desenvolvido em Java utilizando Java Swing.  O projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos, criação de interfaces gráficas, eventos de teclado, colisões, listas, temporizadores e lógica de jogos.
